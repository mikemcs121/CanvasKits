# Highland Cow children's kit

Created October 12, 2026 for ages 8-14: four steps and seven ready-to-use acrylic colors, with no mixing. Palette: mint green, caramel tan, dark brown, cream, pink, black and white. The selected target is a full-body shaggy calf on mint green, with six large brown tufts.

## Edit sources

- `assets/generated-source.png`: selected artwork from the built-in image-generation tool. No artwork was supplied by the user.
- `assets/geometry.json`: canonical traced masks and palette, regenerated by the builder.
- `assets/reference-master.svg` and `assets/reference-master.png`: matching flat-color target; PNG is rendered from vector geometry at 2400 x 3000, 300 DPI. This is a simplified vector reconstruction of generated artwork, not newly detailed raster paint texture.
- `assets/stage-01.png` through `stage-07.png`: cumulative guide panels, with reserved regions white until their step.
- `assets/page-logo.png`: cow-themed variant of the shared logo, edited with the built-in image tool at the user's request: a small Highland calf on the riverbank, cream ribbons, dark brown lettering, green landscape and turquoise river. The original shared logo is untouched.
- `src/build.cjs`: segmentation, smooth tracing, transfer, stage and reference builder. Every stage reuses the canonical paths. Background is introduced in step 2; tan in 3; cream in 4; pink in 5; brown in 6; black eyes/nostrils and white glints in 7. The four-step guide combines these canonical stages: background (stage 2), coat and horns (stage 4), pink and brown (stage 6), face and drying (final reference). Step 4 uses the exact finished target in the shared flat-drying scene.
- `src/image-prompts.txt`: artwork generation and simplification prompts.
- Shared editable guide plan: `assets/tools/guide-template/kits.json`, entry `highland-cow`. Shared page builder: `assets/tools/guide-template/build.cjs`.

Run from the project root:

```powershell
node "Highland Cow/info/src/build.cjs"
```

This writes candidates and review renders into `tmp/highland-cow-four-steps/`. Visually review the transfer, reference and guide together before copying the three candidate production files into `Highland Cow/`. Then run:

```powershell
node Tools/guide-image-extractor.cjs "Highland Cow"
```

The outline is true vector, 8 x 10 inches, #808080, round joins/caps, 2-point strokes and no filled background. Guide: one US Letter page. Reference: one 8 x 10 page. Print artwork at Actual size / 100%. File checks do not constitute physical transfer testing.

For guide-only edits, run `node assets/tools/guide-template/build.cjs highland-cow`. The guide uses a two-column, two-row layout with larger captions. The previous eight-step production set is preserved in Git commit `331303b`.
