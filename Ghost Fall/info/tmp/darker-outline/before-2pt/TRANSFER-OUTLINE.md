# Ghost Fall: current transfer outline

Use [the SVG](output/svg/8x10/ghost-fall-outline-8x10.svg) for vector uploads. It is exactly 8 x 10 inches, with no background, fine 1.4-point lines, and #A6A6A6 medium-light gray for adults. The PDF uses matching vector lines; transparent PNGs are available at 300 and 600 DPI in output/pdf/8x10. Print at Actual size / 100%.

This revision changes transfer linework only. Existing artwork placement and painting guides are retained. Older centered arrangements have not been represented as newly recomposed portrait designs. The former black/bold transfer files are archived in tmp/transfer-standard/before-transfer. Shared current builder: Fox Fall/tmp/transfer-standard. Earlier exporters must apply the current transfer standard before replacing production files.

The SVG is also copied to the Desktop Canvas Kit Vector Outlines folder. The gray settings have been visually checked on screen, but not physically press-tested.
